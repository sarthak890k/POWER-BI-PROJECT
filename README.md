# ☕ Coffee Shop Sales Analysis — End-to-End SQL + Power BI Project

## 📌 Project Overview
This is an end-to-end data analysis project on coffee shop sales, combining **SQL** for data exploration and business analysis with **Power BI** for interactive dashboarding and visualization.

The project follows a real-world analytics workflow: raw transactional data is first explored and analyzed using SQL to answer core business questions, then transformed into an interactive Power BI dashboard for stakeholders to monitor KPIs, track trends, and make data-driven decisions.

The goal is to demonstrate the full analyst skill set — data cleaning, querying, aggregation, data modeling, DAX, visualization design, and business analysis — across both the query layer and the presentation layer.

---

## 🧭 Project Workflow

1. **Data Preparation** – Cleaned and structured raw coffee shop transaction data (transaction ID, date, store location, product category/type, quantity, unit price, total sales).
2. **SQL Analysis** – Used SQL to explore the data and answer 20+ core business questions (sales performance, product trends, store comparisons, time-based patterns).
3. **Power BI Dashboard** – Modeled the same dataset in Power BI, built DAX measures, and designed an interactive dashboard with KPI cards, trend charts, and slicers so the SQL-derived insights could be explored visually and dynamically.
4. **Business Recommendations** – Translated findings from both stages into actionable recommendations for inventory, staffing, and promotions.

## 📌 Key Insights (SQL + Power BI combined)

- Coffee generated the highest overall revenue among all product categories.
- Morning hours recorded the maximum number of orders and highest customer traffic.
- Weekend sales were consistently higher than weekday sales.
- Certain store locations consistently outperformed others.
- A small number of products contributed a disproportionately large share of total sales.

---

## 💡 Business Recommendations

1. Maintain sufficient inventory for top-selling products to minimize stockouts and ensure consistent availability.
2. Increase staffing during peak business hours to reduce customer wait times and improve service quality.
3. Promote underperforming products through discounts, combo offers, or seasonal campaigns.
4. Expand high-performing product categories with new flavors or variations based on customer preferences.
5. Use identified sales trends to improve inventory planning and seasonal forecasting.
